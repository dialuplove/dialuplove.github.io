# dialuplove.github.io

I’m Andrew. I write, hack, tinker, build, break, rebuild, document the rebuilding (less than I should), and occasionally catch things on fire.

My background is a mix of technology, operations, public service, systems thinking, and learning things the hard way so other people do not have to. I’m most interested in complicated environments where people, data, process, controls, and software all have to cooperate—even though none of them were designed to.

These days, I’m focused on AI-assisted software development, cybersecurity, automation, infrastructure, and building tools that make messy work more understandable. I’m especially interested in provenance, auditability, human-in-the-loop systems, local-first tools, and anything that answers the question: “How do we know this is actually correct?”

Some of my projects are practical. Some are experiments. Some began because I said, “Surely this should be easy,” which is how many excellent mistakes begin.

I run a homelab, maintain too many computers, train models, build dashboards that look like Starfleet interfaces, test old operating systems, automate things that were working perfectly well before I touched them, and try to keep notes so Future Andrew can understand what I was trying to do.

I’m not trying to look like the smartest person in the room. I’m trying to understand the room, find the weak assumptions, and leave the system better than I found it.
